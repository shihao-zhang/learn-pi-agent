# Learn Pi Agent

Chinese-first learning project for Pi, the minimal terminal coding agent harness.

Start here:

- [README-zh.md](README-zh.md) for the full guide.
- [docs/research-notes.md](docs/research-notes.md) for verified source notes.
- `npm run check` to run the local teaching examples.

This repository is educational and unofficial. It explains Pi's harness design through small runnable examples plus Pi-native resource samples under `.pi/`.
